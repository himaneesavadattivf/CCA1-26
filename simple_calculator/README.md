# Simple Calculator

This repository contains a minimal Python calculator.

Usage examples:

Run from the command line:

```bash
python main.py add 2 3
python main.py sub 5 2
python main.py mul 4 3
python main.py div 10 2
python main.py pow 2 8
python main.py mod 10 3
```

The script prints integer results without a decimal when possible.
